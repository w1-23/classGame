# classGame 0.5.0 教材冒险地图与分层场景报告

日期：2026-11-22

## 本版范围

本版把个人玩法入口收敛为“教材冒险地图”，并让森林寻宝记的局内场景跟随教材区域和关卡阶段变化。Windows 安装包已重新构建，但本轮没有执行安装、卸载或希沃真机验收。

## 地图行为

- 按游戏、年级、册次、单元和连续编号关卡组织。
- 每个游戏、每本教材分别保存当前位置和通关记录。
- 直接选择后面的关卡只移动当前位置，不补记中间关卡成绩。
- 正式界面不提供“演示通关与前进”，只有真实完成关卡才写入成绩。
- 通关后先保存成绩，再显示主角移动，返回地图后恢复当前位置。
- 地图一次显示 7–12 个连续关卡节点，沿用资产包参考稿的 12 点路线构图，不再把当前单元只有两三个节点铺成大片空地图。
- 地形、河道、木桥、树簇、山体和岩石使用资产包内的 Canvas 绘制代码与原始基件重建，桥面沿实际道路与河道交叉处生成。
- 六个目标视口下页面不产生整体纵向或横向滚动；地图内部可独立滚动查看单元。

## 局内场景联动

跑酷区域由教材单元主题决定，单元内再按题目进度进入三个场景阶段。实装为六主题十八阶段：

| 教材区域 | 阶段 1 | 阶段 2 | 阶段 3 |
|---|---|---|---|
| 森林 | 阳光林地 | 密林小径 | 林间营地 |
| 溪谷 | 溪边栈道 | 木桥水湾 | 瀑布营地 |
| 山谷 | 石径山谷 | 岩壁小径 | 山巅风口 |
| 果园 | 秋日果园 | 果树林道 | 丰收营地 |
| 海岸 | 晴空海湾 | 海边栈桥 | 落日港湾 |
| 雪原 | 松林雪原 | 冰湖驿站 | 星光营地 |

场景会实际改变天空渐变、远山轮廓、地面材质、树冠颜色、水岸、桥梁、帐篷、营地灯光、果园、灯塔、月光和星空。地图的主体构图直接采用压缩包参考稿的分层 Canvas 绘制方式和 12 点路线几何，树、山、石、桥和河道由 `js/adventure-map-art.js` 与 `js/map-primitives.js` 实际绘制；局内两侧树群继续使用由包内 SVG 确定性光栅化的 2x PNG，避免 WebGL 和录屏时出现 SVG 纹理异常。角色、UI、粒子和音频继续使用工程内的 Kenney 正式资产。

地图资产导入记录见 `docs/licenses/classgame-map-art.txt`，压缩包 SHA-256 为 `6C65F2FA72D6E7B339379D27B3FD54C5EBAE7F521DED4C808EFD8455D80520D8`。只导入运行时需要的矢量基件、清单和来源记录，没有把预览页或示例数据冒充正式游戏数据。

同时修复了一个参数链路问题：`mountRunnerGame` 之前没有把 `theme` 和 `areaNames` 传入 Phaser 场景，导致所有教材单元都显示默认林地。现在 HUD 区域名、场景主题和阶段进度会与当前教材和关卡一致。

## 实际验证

已执行：

```powershell
conda run --no-capture-output -n GAME node --check js/app.js
conda run --no-capture-output -n GAME node --check js/adventure.js
conda run --no-capture-output -n GAME node --check js/runner-phaser.js
conda run --no-capture-output -n GAME node tests/smoke.mjs
conda run --no-capture-output -n GAME python tools/validate_content.py
conda run --no-capture-output -n GAME npx playwright test
```

结果：

- 静态语法检查通过。
- Smoke test 通过。
- 内容校验通过：26 个内容包、12 册英语、12 册语文、4476 条学习内容。
- Playwright 36 项通过，覆盖六档视口、六区域地图资产、六主题十八阶段场景、三车道变道、碰撞、暂停、连续关卡、记忆翻牌锁定、诗词填空和班级计分。
