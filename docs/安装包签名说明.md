# 安装包签名说明

当前在本机证书存储 `Cert:\CurrentUser\My` 中创建了代码签名证书：

- 发布者：`CN=王自强`
- 算法：RSA 2048 / SHA-256
- 用途：代码签名
- 私钥：保留在本机用户证书存储，不写入仓库

`package.json` 的 `build.win.certificateSubjectName` 已配置为完整主题名 `CN=王自强`，后续执行 `npm run dist` 会自动用该证书签名安装包和内部可执行文件。

## 手动签名

如果只需要重新签名已有安装包：

```powershell
$signtool = 'C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\signtool.exe'
$installer = 'release\classGame-0.8.0-x64-setup.exe'
& $signtool sign /fd SHA256 /n '王自强' /tr http://timestamp.digicert.com /td SHA256 $installer
& $signtool sign /fd SHA256 /n '王自强' $installer
```

第一条命令尝试加入时间戳；如果时间戳服务器不可达，可用第二条命令仅做本地签名。

## 验证

```powershell
Get-AuthenticodeSignature -LiteralPath 'release\classGame-0.8.0-x64-setup.exe' |
  Select-Object Status,StatusMessage,@{n='Publisher';e={$_.SignerCertificate.Subject}}
```

这是**自签名证书**：签名中的发布者名称是“王自强”，但不等于全球可信的代码签名证书。未把该证书加入受信任根的其他电脑仍可能显示“未知发布者”或 SmartScreen 警告。若要让所有用户都无警告安装，需要从受信任 CA 购买/申请代码签名证书，尤其是 EV 代码签名证书。
