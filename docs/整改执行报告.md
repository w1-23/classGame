# classGame 全量整改执行报告

日期：2026-11-21
版本：`0.2.0`
范围：`w1-23/classGame` 本地临时工作区源码级整改

## 第一阶段：源码审查与问题复现

已逐项检查原有页面、游戏工厂、题库、音频、Electron 外壳、构建脚本和测试。确认原跑酷存在三项根因：

1. `.lanes` 使用横向三列 DOM 布局，视觉上伪装成三条跑道。
2. 角色使用 `top` 改变位置，门体使用另一套坐标体系，变道和碰撞没有共享空间模型。
3. 场景没有消失点、纵深投影、远景到近景缩放和共用车道坐标。

另外发现并修复一个真实运行缺陷：车道金币/宝石装饰引用了不存在的投影 `x`，导致精灵被放在画布左侧。

## 第三阶段：三通道跑酷重做

跑酷已改为 Phaser 3 场景：

- 三条跑道共享消失点。
- 角色固定在近端，支持左右变道。
- 三道答案门从远景向角色移动，门体、门柱、门楣、答案牌、地面阴影和粒子都使用同一投影。
- 正确答案开门、冲门、粒子、金币、连击、镜头闪光。
- 错误答案角色踉跄、门体变红、正确门高亮、顶部正确答案提示。
- 顶部 DOM 答案对照条只解决远景文字可读性，碰撞仍由场景门体完成。
- 完整流程包括倒计时、暂停、恢复、下一题、十题结算。
