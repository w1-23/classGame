# classGame 0.4.0 · 森林寻宝记与诗词小剧场

日期：2026-11-22  
分支：`master`  
版本：`0.4.0`

## 本轮目标

按示意图重做跑酷主界面与连续游玩流程，并把古诗节拍替换成老师可控制的诗词共读小剧场。本轮已重新生成 `0.4.0` Windows 安装版与便携版，不把示意图当作运行截图。

## 森林寻宝记

- 场景内保留左上标题与区域进度、中上纸任务牌、右上金币与暂停，不再使用顶部大白 HUD。
- 三题组成一段冒险，共三段九题；只在 Journey 开始时倒计时一次。
- 木柱纸牌门和角色脚底、金币共用同一套透视坐标；树木、灌木和石块落在道路边缘之外。
- 左右变道、答案门碰撞、正确冲门粒子、错误踉跄、金币实际拾取、暂停/恢复和自动换题均由 Phaser 场景驱动。
- 答对与答错都只显示底部局部胶囊反馈，不再弹出大面板，不需要点击“继续”。
- 完成后任务牌显示“抵达终点”，底部切换为“林间小径 / 再走一次 / 完成”。

## 诗词小剧场

- 可在《静夜思》《春晓》之间切换。
- 每首诗支持播放当前句、重听、上一句和下一句；老师控制课堂进度。
- 加入“补全诗句”理解互动，完成整首共读后进入本机结算。
- 新增 8 段分句范读 WAV，写入内容包 `lineAudio` 字段。
- 系统只记录共读与理解互动，不冒充朗读发音评分。

## 资产与授权

- 角色、场景、UI、粒子、音效继续使用仓库现有 Kenney CC0 资产。
- 跑酷 BGM 继续使用本地 CC0 `Overworld Theme`，不循环短 jingle。
- 古诗分句音频由本机 Windows `Microsoft Huihui Desktop` TTS 生成，尚未经过教师逐条试听，状态仍为待审核。
- 现有 Toon Characters 包没有背向跑步帧，本轮使用正式正面跑步帧，没有伪造背向动画。
