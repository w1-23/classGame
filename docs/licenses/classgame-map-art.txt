classGame map art handoff
==========================

Imported: 2026-11-22
Source archive: classGame_map_art_handoff_20261122.zip
Archive SHA-256: 6C65F2FA72D6E7B339379D27B3FD54C5EBAE7F521DED4C808EFD8455D80520D8

The imported vector files under assets/map-art/vector are original classGame
map primitives derived from the approved classGame map drawing rules. They are
not third-party stock artwork.

The Phaser runner uses PNGs in assets/map-art/raster/. They are deterministic
2x rasterizations of the same imported SVG files, generated by
tools/rasterize_map_assets.mjs so WebGL and video capture do not depend on
runtime SVG texture decoding.

Imported runtime assets:
- bridge-topdown.svg
- cloud.svg
- mountain.svg
- mountain-snow.svg
- pine.svg
- pine-snow.svg
- rock.svg
- tree-autumn.svg
- tree-round.svg
- tree-slim.svg

The handoff artistically references the project's existing Kenney Toon
Characters frames. Those character files are not duplicated in this import;
the project continues to use the already documented Kenney CC0 character
files and retains their license notices.
