# 第三方许可与素材说明

日期：2026-11-21

## 程序代码

本项目运行时代码为本次独立实现。没有复制 Ehaan Games、EndlessRunnerGame、PULSEGRID 或 Offline Quiz Host 的源码。参考内容限于通用玩法机制、项目结构和交互思路。

## 范读音频

`audio/zh/` 和 `audio/en/` 中的范读由本机 Windows TTS 在开发阶段生成，不属于第三方程序素材。正式发行前必须由教师逐条试听、确认或替换为有明确授权的录音。审核表见 `docs/范读审核清单.md`。

## 未纳入发布包的内容

- `vendor/kenney/` 中保存的是下载的完整原始素材包，用于来源追溯；Electron 发布包只打包实际使用的 `assets/kenney/` 与 `audio/kenney/`。
- `vendor/kenney/*.zip` 不进入运行时安装包。
