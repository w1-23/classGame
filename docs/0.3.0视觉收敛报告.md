# classGame 0.3.0 视觉收敛报告

日期：2026-11-22
基准提交：`a31b8831d8c75a7d611a6feb1daf38e9132a13a6`
工作方式：本地临时目录源码整改，Anaconda 环境 `GAME`

## 本轮目标

本轮不新增玩法、不更换引擎，只收敛界面层级、统一已有 Kenney 资产使用方式并补齐响应式与视觉回归。

## 已完成

### 页面与 HUD

- 游戏运行态隐藏全局 Header。
- 跑酷只保留三层：单一 HUD、Phaser 场景、三段式控制条。
- HUD 合并题号、题目、得分、金币、连击、暂停和底部进度条。
- 删除独立的答案对照大卡片，答案只在门牌和反馈中出现。
- 删除门体顶部星形徽章、内部发光框、星形角色光晕和镜头闪光。
- 正确/错误只使用一个反馈面板，不再叠加顶部 Banner。
- 暂停面板提供继续、音频测试、设置、全屏和返回大厅。

### 跑酷场景

- 三条跑道统一为 `#BDA77F` 地面，车道只用白色虚线区分。
- 蓝、绿、琥珀色只用于三扇门牌。
- 三扇门统一使用 `block_green.png` 门柱与门楣、`door_closed/open.png` 门扇。
- 主角使用 Male Adventurer，目标高度固定为场景高度的 25%，等比缩放。
- 减少金币和侧边装饰密度；同时可见侧边装饰最多 8 个、车道收集物最多 4 个。
- 正确反馈最多 10 个星形粒子和 8 个火花；错误反馈不使用红色爆炸粒子。
- 加入 OpenGameArt/Louswan《Overworld Theme》alternate 循环 BGM，音量 0.16；暂停时降低到静音。

### 其他五种玩法

- 删除 118px 高的大型 `activity-banner`。
- 听音、拼装、记忆、音游、班级战统一为紧凑标题栏和内容区。
- 统一平面 CSS 按钮，不再以 Kenney 亮面按钮图片作为大面积控件背景。
- 记忆牌背只保留一个星形图案，无渐变和高光。
- 班级战固定为蓝队与琥珀队。
