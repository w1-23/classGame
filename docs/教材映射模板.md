## 内容包映射规则

1. 只记录教材版本、册次、单元和学习点，不复制教材 PDF、整篇课文、插图或配套录音。
2. 游戏题干、选项、提示语自行编写。
3. 每个知识点保留稳定 ID，避免后续内容更新导致存档失效。
4. 教师确认后再将 `reviewed` 标记为 `true`。
5. 新增内容时运行 `npm run validate`，检查重复选项、缺失音频和拼音。
