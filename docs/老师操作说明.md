# 学习闯关乐园 · 老师操作说明

## 安装与开始

当前源码版本为 `0.4.0`，GitHub 仓库不包含构建产物，本地交付目录中已生成：

- 安装版：`release/classGame-0.4.0-x64-setup.exe`
- 便携版：`release/classGame-0.4.0-x64-portable.exe`

两者均未签名，Windows 可能显示“未知发布者”。本轮已验证免安装目录程序，但尚未执行安装版卸载和便携版断网双击验收。

1. 开发或验收当前源码时，在 Anaconda `GAME` 环境运行 `npm start`。
2. 正式 Windows 安装包重新生成后，再补充本节的安装版与便携版文件名。
3. 首次进入后可在右上角「设置」选择内容包，并分别调整范读音量和界面音效音量。
4. 需要保存课堂进度时，点击右上角「存档」导出 JSON；换机后再导入。
5. 点击「音频测试」可确认界面音效和范读播放正常。

## 森林寻宝记操作

1. 键盘：左右方向键变道，上方向键回到中间。
2. 屏幕按钮：左道、中间、右道。
3. 触屏：点击底部“左路 / 中路 / 右路”，也可以点击 Phaser 场景中的对应跑道。
4. 暂停：点击右上角「暂停」；暂停面板可继续、音频测试、设置、全屏或返回大厅。

每段冒险 3 题，共 3 段。游戏只在开始时倒计时一次；选择跑道后，木柱纸牌门驶过角色并自动判定。答对或答错后会短暂显示局部反馈并自动换题，不需要点击“继续”。

金币只在实际经过金币所在跑道时拾取。抵达终点后可选择“林间小径”返回大厅、“再走一次”重新开始，或“完成”查看本局回顾。

## 课堂玩法

1. 个人冒险：森林寻宝记、听音找精灵、拼音/单词拼装、记忆翻牌配对。
2. 全班挑战：先进入老师主控大厅，再选择诗词小剧场或小组知识守护战。
3. 诗词小剧场支持《静夜思》《春晓》；老师可逐句播放、重听、上一句、下一句，并控制何时进行诗句补全。系统只记录共读与理解互动，不冒充朗读发音评分。
4. 小组守护战由两组轮流答题，学生代表选择答案，老师点击“确认正确”或“需复习”后计分。
5. 每局结束显示星级、得分、正确率、金币、最高连击和知识回顾。

## 音频说明

- 正确题只播放正确/金币音效；错误题只播放一次错误提示音，随后播放该题范读。
- 跑酷使用约 41 秒的本地 CC0《Overworld Theme》循环 BGM；短 jingle 只在结算时播放一次。
- 若教室不需要声音，可把界面音效调到 0；范读音量可单独调整。
