# 学习闯关乐园 · 老师操作说明

## 安装与开始

当前源码版本为 `0.3.0`，本轮尚未重新生成 Windows 安装包。现有 `0.2.0` 安装包为历史构建，跑酷界面与本文不同；不要把旧安装包当作 0.3.0 的视觉验收结果。

1. 开发或验收当前源码时，在 Anaconda `GAME` 环境运行 `npm start`。
2. 正式 Windows 安装包重新生成后，再补充本节的安装版与便携版文件名。
3. 首次进入后可在右上角「设置」选择内容包，并分别调整范读音量和界面音效音量。
4. 需要保存课堂进度时，点击右上角「存档」导出 JSON；换机后再导入。
5. 点击「音频测试」可确认界面音效和范读播放正常。

## 跑酷操作

1. 键盘：左右方向键变道，上方向键回到中间。
2. 屏幕按钮：左道、中间、右道。
3. 触屏：点击底部左道、中间、右道，也可以点击 Phaser 场景中的左侧、中间、右侧跑道。
4. 暂停：点击右上角「暂停」；暂停面板可继续、音频测试、设置、全屏或返回大厅。

答案直接标在三道门上方；真正参与碰撞的是同一批场景门体，没有额外重复的答案对照条。

## 课堂玩法

1. 个人冒险：三道门跑酷、听音找精灵、拼音/单词拼装、记忆翻牌配对。
2. 全班挑战：先进入老师主控大厅，再选择古诗朗读节拍或小组知识守护战。
3. 古诗节拍只判断击打节拍窗口，不冒充朗读发音评分；发音是否正确由老师确认。
4. 小组守护战由两组轮流答题，学生代表选择答案，老师点击“确认正确”或“需复习”后计分。
5. 每局结束显示星级、得分、正确率、金币、最高连击和知识回顾。

## 音频说明

- 正确题只播放正确/金币音效；错误题只播放一次受挫和错误提示音。
- 跑酷使用约 41 秒的本地 CC0《Overworld Theme》循环 BGM；短 jingle 只在结算时播放一次。
- 若教室不需要声音，可把界面音效调到 0；范读音量可单独调整。
