# 学习闯关乐园 · 老师操作说明

## 第 1 页：安装与开始

1. 双击便携版文件夹中的 `学习闯关乐园.exe`，不需要联网、账号或安装开发环境。
2. 首次进入后可在右上角「设置」中选择内容包，并分别调整背景音乐、范读和界面音效音量。
3. 需要保存学生或班级进度时，点击右上角「存档」，可导出 JSON 备份文件；换机时再导入。
4. 点击「音频测试」可确认界面音效和范读播放正常。

## 第 2 页：课堂玩法

1. 个人冒险：适合单人练习，包含三道门跑酷、听音找精灵、拼音/单词拼装、记忆翻牌配对。
2. 全班挑战：适合一块希沃大屏，由老师或学生代表操作；古诗节拍不判断发音准确度，只做节奏提示，朗读是否正确由老师确认。
3. 小组守护战：两组轮流答题，老师点「确认正确」或「需复习」，系统负责计分和能量条。
4. 每局结束都会显示得分、正确率和知识回顾；请利用回顾页带领学生订正。
5. 若学校设备没有麦克风，不影响任何玩法通关。
