# 学习闯关乐园 · 老师操作说明

## 安装与开始

1. 安装版：双击 `classGame-0.2.0-x64-setup.exe`，按向导选择安装目录。
2. 便携版：直接双击 `classGame-0.2.0-x64-portable.exe`，不需要安装 Node、npm、Python 或 Anaconda。
3. 首次进入后可在右上角「设置」选择内容包，并分别调整范读音量和界面音效音量。
4. 需要保存课堂进度时，点击右上角「存档」导出 JSON；换机后再导入。
5. 点击「音频测试」可确认界面音效和范读播放正常。

## 跑酷操作

1. 键盘：左右方向键变道，上方向键回到中间。
2. 屏幕按钮：左道、中间、右道。
3. 触屏：点击三条跑道或顶部答案对照条，也可以在 Phaser 场景中点击左侧、中间、右侧。

顶部“答案对照”只负责远景可读性；真正参与碰撞的是场景里的三道立体门。

## 课堂玩法

1. 个人冒险：三道门跑酷、听音找精灵、拼音/单词拼装、记忆翻牌配对。
2. 全班挑战：先进入老师主控大厅，再选择古诗朗读节拍或小组知识守护战。
3. 古诗节拍只判断击打节拍窗口，不冒充朗读发音评分；发音是否正确由老师确认。
4. 小组守护战由两组轮流答题，学生代表选择答案，老师点击“确认正确”或“需复习”后计分。
5. 每局结束显示星级、得分、正确率、金币、最高连击和知识回顾。

## 音频说明

- 正确题只播放正确/金币音效；错误题只播放一次受挫和错误提示音。
- 短 jingle 不在游戏中循环，只在结算时播放一次。
- 若教室不需要声音，可把界面音效调到 0；范读音量可单独调整。
