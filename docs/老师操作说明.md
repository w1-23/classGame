# 学习闯关乐园 · 老师操作说明

## 安装与开始

当前源码版本为 `0.5.0`，GitHub 仓库不包含构建产物。0.4.0 的安装包和便携包仅是旧版记录，不代表 0.5.0 已完成安装、卸载和断网验收。

1. 开发或验收当前源码时，在 Anaconda `GAME` 环境运行 `npm start`。
2. 正式 Windows 安装包重新生成后，再补充本节的安装版文件名。
3. 首次进入后可在右上角「设置」调整范读音量和界面音效音量。
4. 需要保存课堂进度时，点击右上角「存档」导出 JSON；换机后再导入。
5. 点击「音频测试」可确认界面音效和范读播放正常。

## 教材冒险地图

1. 在大厅选择个人玩法后进入教材冒险地图。
2. 顶部选择游戏和教材，教材按年级、上下册分组。
3. 中间标签切换单元；地图上的连续编号对应当前教材的关卡。
4. 点击编号选择关卡；下方会显示本关知识点、任务量、记录和地形。
5. 点击“主角前往第 N 关”开始游戏。完成后先保存成绩，再前往下一关。
6. 每个游戏、每本教材的当前位置和通关记录分别保存。直接跳到后面的关卡不会自动补记中间成绩。

## 森林寻宝记操作

1. 键盘：左右方向键或数字 1/2/3 变道。
2. 屏幕按钮：左路、中路、右路。
3. 触屏：点击底部“左路 / 中路 / 右路”，也可以点击 Phaser 场景中的对应跑道。
4. 暂停：点击右上角「暂停」；可继续、重玩本关、返回地图或返回大厅。

每关题量由当前教材内容决定，题量较多时按阶段推进。场景会随教材单元和关卡阶段改变：森林、溪谷、山谷、果园、海岸、雪原六套主题，每套三个阶段。游戏只在开始时倒计时；木柱纸牌门驶过角色后自动判定，并短暂显示局部反馈。

抵达终点后可选择“返回关卡”、“再走一次”或“完成”查看本局回顾。

## 课堂玩法

1. 个人冒险：森林寻宝记、听音找精灵、拼音/单词拼装、记忆翻牌配对。
2. 全班挑战：先进入老师主控大厅，再选择诗词填空闯关或小组知识守护战。
3. 诗词填空闯关支持《静夜思》《春晓》；老师可逐句播放、重听、上一句、下一句，并控制何时进行诗句补全。系统只记录共读与理解互动，不冒充朗读发音评分。
4. 小组守护战由两组轮流答题，学生代表选择答案，老师点击“确认正确”或“需复习”后计分。
5. 每局结束显示星级、得分、正确率、金币、最高连击和知识回顾。

## 音频说明

- 正确题只播放正确/金币音效；错误题只播放一次错误提示音，随后播放该题范读。
- 跑酷使用约 41 秒的本地 CC0《Overworld Theme》循环 BGM；短 jingle 只在结算时播放一次。
- 若教室不需要声音，可把界面音效调到 0；范读音量可单独调整。
