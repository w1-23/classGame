# 内容包审核说明

## 内容边界

- 当前内容包含语文 1–6 年级上下册字词、英语 1–6 年级上下册开源同步词表、一年级上册拼音和公共领域古诗。
- 未复制教材 PDF、整篇现代课文、出版社插图或配套录音。
- 题干、干扰项和课堂提示语为自编内容；古诗原文为公共领域文本。
- 后续接入学校实际教材时，只记录出版社、版次、册次、单元和核对日期，不整本搬运教材内容。

## 审核要求

1. 每个题目必须有且仅有一个正确答案。
2. 每个题目至少有两个互相独立且可信的干扰项。
3. 每个范读音频必须由教师试听并核对。
4. 中文多音字、轻声、变调必须结合教学语境确认。
5. 英语口音版本需统一，当前使用 Windows 本机美式女声生成，正式发行前应替换为人工审核录音或授权音频。
6. 运行 `npm run validate` 执行结构与音频完整性校验。

- 26 个内容包、4476 条学习内容已完成自动结构校验。
- 语文 12 册共 3141 条字词，英语 12 册共 1288 条词表，拼音 47 条。
- 两首古诗已离线打包；古诗全年级覆盖尚未完成。
- 范读为本地 Windows TTS 生成，仅用于原型验证；正式发行前必须教师逐条审核。
