## 安装与离线

- [ ] 断开网络后，双击 `LearningAdventurePark-installer.exe` 可完成安装。
- [ ] 安装后桌面和开始菜单出现「学习闯关乐园」快捷方式。
- [ ] 断网状态下应用可启动并进入首页。
- [ ] 运行过程中无 CDN、在线字体、外部 API、账号或服务器请求。
- [ ] 卸载后应用目录与快捷方式被清理。

## 大屏可读性

- [ ] 全屏 16:9 下标题、题目、选项、结算文字清晰可读。
- [ ] 按钮触控区足够大，无遮挡。
- [ ] 背景与文字对比度适合教室环境。
- [ ] 全部 6 个玩法入口均可点击进入。

## 输入

- [ ] 单点触屏可完成首页、设置、玩法选择。
- [ ] 三道门跑酷可使用屏幕按钮切换通道。
- [ ] 拖拽类操作可用鼠标完成。
- [ ] 键盘方向键可用。
- [ ] 不插麦克风仍可完成全部玩法。

## 音频

- [ ] 点击音、正确反馈、错误反馈均可播放。
- [ ] 背景音乐默认静音，调高后可播放。
- [ ] 范读音量、界面音效、背景音乐可分别调节。
- [ ] 中文 10 题范读全部播放正常。
- [ ] 英语 10 题范读全部播放正常。
- [ ] 两首古诗范读播放自然。

## 玩法闭环

- [ ] 三道门跑酷完成 10 题并进入结算。
- [ ] 听音找精灵完成 10 题并进入结算。
- [ ] 拼装挑战完成 10 题并进入结算。
- [ ] 记忆翻牌配对完成全部配对并进入结算。
- [ ] 古诗朗读节拍完成一轮并进入结算。
- [ ] 小组知识守护战完成一轮并进入结算。
- [ ] 每局均显示得分、正确率与知识回顾。

## 存档

- [ ] 完成一局后本机进度更新。
- [ ] 存档导出为 JSON。
- [ ] 存档导入后进度恢复。
- [ ] 应用重启后设置与进度保留。
